# Master Skill

A portable Agent Skill (see `SKILL.md`) that guides **and executes**, through an AI coding agent, the from-scratch construction of an agentic design system — for any team, in any project.

It carries **no technical dependency on the Clone**. A team can adopt the Master Skill without ever installing the Clone, and vice versa — they are two independent paths to the same non-negotiable foundation.

## What makes this different from a template

The Master Skill doesn't hand a team a pre-built starting point to copy — that's what the Clone is for. It walks an agent through building one from scratch, in the target project, with a human in the loop at every structural decision: component architecture, token structure, governance setup, audit configuration, and agent trigger conditions.

The actual step-by-step execution logic is a separate, follow-up piece of work — this README only introduces the skill's purpose and boundaries.
